# EDW themes

This module provides a collection of themes.

## Installation

1. Add the following snippet to the `repositories` section of your `composer.json` file:
```
{
    "type": "git",
    "url": "https://github.com/eaudeweb/edw_themes.git"
}
```

2. Run
   ```composer require eaudeweb/edw_themes:^1.0```

3. Enable the module:
   ``drush en edw_themes``
